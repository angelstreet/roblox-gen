# Thornwood Druid (cold Haiku test, 2026-11-09)

Bark-and-moss set built by a Haiku agent from this repo's docs: antler crown, bark pauldrons, moss mantle, bone gorget,
gnarled staff, plus shirt, pants and face. Kept as a record of the test, not as a quality reference.

- Checks: passes size boxes, tris, watertight, texel density and clip_check.
- Below the bar: no hair, thin stick antlers, flat mantle, plain staff, and the clothing is Crystal Vanguard's layout recoloured.
  The agent stopped after 2 rounds. Not uploaded or tested in Studio.
- Scripts keep the Crystal Vanguard `*_cv.py` names (it was copied from that example). Textures in `textures/`.
- Rebuild: `./run_all.sh <tag>`.
